Nothing is mapped to / yet, so wonder-slim shows this page in its place. It's only here in development: deployed, / answers 404 until the application maps it.

Use your own page

Map / to a component in your application's constructor:

public Application() {
	RouteTable.defaultRouteTable().map( "/", Main.class );
}

Any component will do, and Main is the traditional one. Once / is mapped, it answers instead of this page, in development too.
