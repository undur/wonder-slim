Vanishing update container

Deliberately wrong-by-design: the AjaxUpdateContainer sits inside a conditional, and the action fired from inside it turns that conditional off — the shape of deleting the last item of the list the container is conditioned on. The container never renders during the update pass, so the framework must answer with an explanatory 500 (body naming the container, the page and the likely cause), not an empty one.
